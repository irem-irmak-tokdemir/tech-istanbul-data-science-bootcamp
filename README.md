# Tech Istanbul Data Science Bootcamp

Tech Istanbul Data Science Bootcamp kapsamında hazırladığım çalışmalar, ödevler ve bitirme projesi.

## 📚 Çalışmalar

| No | Çalışma                               | Konu                               |
| -- | ------------------------------------- | ---------------------------------- |
| 01 | Sayı Yaklaşma Oyunu                   | Python Temelleri                   |
| 02 | Kütüphane Yönetim Sistemi             | Python, Listeler, Sözlükler        |
| 03 | Dosyalı Kütüphane Yönetim Sistemi     | Dosya İşlemleri                    |
| 04 | Basit Doğrusal Regresyon              | Makine Öğrenmesi, Regresyon        |
| 05 | Regresyon Modelleri Karşılaştırması   | Linear Regression, Ridge, PCR, PLS |
| 06 | Doğrusal Regresyon ve Yapay Sinir Ağı | Regresyon, MLP                     |
| 07 | K-Means Müşteri Segmentasyonu         | Kümeleme, Elbow, Silhouette        |
| 08 | IMDB Duygu Analizi                    | NLP, RNN                           |
| 09 | Fashion-MNIST Görüntü Sınıflandırma   | CNN                                |
| 10 | Bitirme Projesi                       | Regresyon, Kümeleme, NLP, CNN      |

## 🏆 Bitirme Projesi

Bitirme projesinde bootcamp boyunca öğrenilen farklı veri bilimi ve makine öğrenmesi yöntemleri tek bir menü tabanlı uygulama içerisinde birleştirilmiştir.

Uygulama içerisinde:

1. Ev fiyatları için regresyon analizi
2. Müşteri segmentasyonu
3. Film yorumları için duygu analizi
4. Fashion-MNIST veri seti ile görüntü sınıflandırma

çalışmaları bulunmaktadır.
